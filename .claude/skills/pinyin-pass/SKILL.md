# 补拼音

引擎会自动把 `PINYIN` 表里的词注在字的上方（每行同一个词只注第一次，换行不拆词，设置里可关）。这个工序只负责把表写对、写全。

## 管理约定

| 协议面 | 约定 |
|---|---|
| Tools | `python3 -I tools/pinyin_scan.py js/story/<id>.js`；读音拿不准时用 WebSearch 查（汉典、教材） |
| Rules | 按「词」注，不按单字注（单于 → chán yú，不要只注「单」）；音节数 = 字数；带声调符号 |
| Verification | pinyin_scan 显示「没有问题」；`node tools/playtest.js <id>` 通过 |

## 选字标准（小学三到六年级）
要注：
- **人名、地名、族名、官名**，全部注（张骞、陇西、月氏、郡守）
- **多音字读的不是最常见的音**（单于 chán、大宛 yuān、降人 xiáng、出塞 sài、列传 zhuàn、哨卡 qiǎ、少长 shào zhǎng）
- **文言引文里的特殊读法**（衣其皮革 yì、畜肉 chù）
- **小学课本里少见的字**（骞、燧、镝、穹、夯、戍、徙、皿）
- 生活里少见的词（器皿、屋檐、牦牛）

不注：小学低年级就会的常用字，以及读最常见读音的多音字（长安的「长」、汉朝的「朝」、快乐的「乐」）。注得太多，满屏拼音反而难读。

## 流程

### 1. 扫
```bash
python3 -I tools/pinyin_scan.py js/story/<id>.js
```
先看「拼音表问题」（音节数不对、剧本里没用到的词），修掉。再看「还没注音的字」：少见的排在前面，每个附一处上下文。

### 2. 挑候选、查读音
按选字标准挑出候选，**按词写**（看上下文，组成剧本里实际出现的词）。读音拿不准的（尤其古人名、古地名、文言），WebSearch 查，查不到权威依据就标「存疑」。

### 3. 给用户确认（要问用户）
把候选分成三组给用户看：
- 人名地名
- 多音字（写出这里的读法和常见读法）
- 生僻字
- 存疑的读音单独列出，说明有几种说法

用 AskUserQuestion 问：全部采纳 / 去掉某几组 / 有要改的。用户说某个词孩子认识，就不注。

### 4. 写入
把确认的词加进剧本的 `const PINYIN = { ... }`，每行四个，跟现有格式一致。再跑一次 pinyin_scan，必须显示「没有问题」。

### 5. 验证
- `node tools/playtest.js <id>` 通过（引擎发现音节数不对会报错）
- 浏览器看一眼对话框、建筑招牌、史料卡标题上的拼音位置
