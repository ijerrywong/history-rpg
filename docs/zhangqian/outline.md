## 决策点 1：匈奴营地「什么时候走？」

- **探索**：营地里可以打听到的消息：「单于说月氏在北边」「月氏人恨匈奴」「最近看守松了」（只有《史记》这么写，附卡「两本书不一样」）；和甘父去打猎，补口粮
- **选项**：
  1. **现在就走**：看守还紧 → 推演：被追回，丢 3 个随从，再等几年才有机会，然后进入选项 2 的情况（标「历史上没有发生」）
  2. **等看守松了再走**（史实的做法）
  3. **不走了，留在草原** → 直接进入结局 C
- **带不带妻儿**（史书没写第一次逃走时有没有同行）：带上，口粮消耗多、走得慢；不带，归途再被抓回营地时会有一段重逢。两种都标「史书没写」
- **依据卡**：一点点松下来、两本书不一样、会射箭的堂邑父

## 决策点 2：大月氏王庭「怎么劝？」

- **探索**：在大月氏、大夏打听：「这里土地肥，少强盗」「他们觉得汉朝太远」「大夏东南有个身毒国，有蜀地的货物」（史实，张骞当时就听说了）
- **选项**：
  1. **讲报仇**（汉朝出发前就知道月氏恨匈奴）→ 月氏回答「地方好、过得安乐、汉朝太远」，不答应（史实）
  2. **许诺重礼**（花 2 次许诺）→ 依然不答应。类比：后来张骞带着大批财物去乌孙，也没能说动（史实）
  3. **请月氏派人跟我回汉朝看看**（需要先打听到「他们觉得汉朝太远」）→ 推演：月氏派两名使者同行。类比：乌孙使者到汉朝亲眼看过之后，乌孙开始看重汉朝（史实）
  4. **不劝了，把西域的地理、物产记下来**（史实中他最后的收获）→ 消息 +2
- **依据卡**：月氏为什么说「不」、两次出使带的东西不一样、乌孙也说「再想想」、看一看就明白了

## 决策点 3：大夏「从哪条路回家？」

- **选项**：
  1. **沿南山，从羌中走**（史实）→ 又被匈奴抓住，押回营地；一年多后单于去世、营地大乱，趁乱逃回（史实）
  2. **往北，直接穿过匈奴**（「少北则为匈奴所得」是张骞回国后才说的，游戏里**不提示**）→ 推演：很快被抓住，随从减员更多；之后同样赶上内乱
  3. **往东南，绕道身毒回蜀地**（需要先打听到身毒的消息）→ 进入结局 D
  4. **不回去了，留在大夏** → 进入结局 C
- **依据卡**：回家的路选哪条、河西什么时候变成汉朝的（结局时才发）
